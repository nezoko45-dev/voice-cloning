# VoiceAgent Pocket

A Manifest V3 Chrome extension pairing OpenRouter chat with speech generated by a **self-hosted local TTS API**. Speech generation and playback no longer depend on the PocketWebTools webpage.

## Features

- OpenRouter chat with configurable API key, model, and system prompt.
- Local Fish Speech API integration using the native MessagePack `POST /v1/tts` endpoint.
- Local endpoint, optional saved reference voice ID, and optional local bearer token are configurable in extension settings.
- Generated audio is played from the extension's offscreen document, so the popup can close and the user can switch tabs or applications while playback continues.
- Optional background microphone recognition when supported by the installed Chrome environment.

## Install the extension

1. Clone or download this repository.
2. Open `chrome://extensions`, enable **Developer mode**, and choose **Load unpacked** for the folder containing `manifest.json`.
3. Open VoiceAgent Pocket → settings and enter your OpenRouter API key. OpenRouter remains the chat provider.
4. Install and start a local Fish Speech server as described below.
5. In extension settings, set the endpoint to `http://127.0.0.1:8080/v1/tts` (or the local address/port you chose), then click **Save settings**.
6. Send a test message. The extension posts speech text to the configured localhost endpoint and plays the returned audio.

## Install Fish Speech locally

Follow the official Fish Speech installation guide and use its own license and hardware requirements before downloading weights:

- Installation: https://speech.fish.audio/install/
- Inference and API server: https://speech.fish.audio/inference/
- Docker setup: linked from the official inference guide.

The official API server loads the model weights at startup. For S2-Pro, the documented source launch pattern is:

```bash
python tools/api_server.py \
  --listen 127.0.0.1:8080 \
  --llama-checkpoint-path checkpoints/s2-pro \
  --decoder-checkpoint-path checkpoints/s2-pro/codec.pth \
  --decoder-config-name modded_dac_vq
```

For Drama 3, use the official model-specific launch command and hardware requirements in the inference guide. The exact install/download commands and model weights can change, so use the upstream guide for the current setup. The API server should listen on loopback, not a public network interface. Verify it is ready with:

```bash
curl http://127.0.0.1:8080/v1/health
```

The official native endpoint is `POST /v1/tts`, with a MessagePack request body and audio response. VoiceAgent Pocket sends MessagePack fields `text`, `format: "wav"`, and (if configured) `reference_id`. If the server is started with `--api-key`, enter that token in the extension's local-server API token field.

### Add a local reference voice (optional)

Use a recording you own or are explicitly authorized to clone. The reference is uploaded only to your own local server, not to a third-party TTS service. Example from the official Fish Speech API documentation:

```bash
curl -X POST http://127.0.0.1:8080/v1/references/add \
  -F id=my-speaker \
  -F "audio=@reference.wav;type=audio/wav" \
  -F "text=Accurate transcript of the reference recording"
```

Then enter `my-speaker` in **Saved local voice reference ID**. This voice setup request goes to your own machine. The extension itself does not ask for, upload, or store voice samples.

## Local endpoint configuration

Default endpoint: `http://127.0.0.1:8080/v1/tts`

You can change it in extension settings, but the extension deliberately accepts only `localhost` or `127.0.0.1` HTTP(S) endpoints to reduce accidental remote transmission. If your local server uses another port, update the port in the endpoint. If the server requires bearer authentication, configure its token locally in settings. The server must accept the Fish Speech native MessagePack API format; an OpenAI-compatible JSON-only endpoint is not interchangeable with this native endpoint.

If the browser reports a connection, CORS, or request error, confirm that the server is running, the endpoint path and port match, the server permits extension-origin requests, and any API token is correct. Keep the server bound to loopback. Do not expose the API port to the public internet.

## Privacy

- **TTS:** speech text is sent only to the configured loopback TTS service. No third-party TTS provider is called. VoiceAgent Pocket does not upload reference audio; the optional voice enrollment command above is run by you directly against your local service.
- **Chat:** user messages and conversation context are sent to OpenRouter and its selected model provider, because OpenRouter chat is intentionally preserved.
- API keys and endpoint settings are stored in `chrome.storage.local`; this is local browser storage, not a secure secrets vault.
- Only clone your own voice or a voice you have explicit permission to use.

## Files

- `manifest.json` — extension permissions and localhost access
- `popup.html`, `popup.css`, `popup.js` — chat UI and local TTS settings
- `background.js` — OpenRouter requests, local speech API requests, and offscreen document lifecycle
- `offscreen.html`, `offscreen.js` — background playback and guarded microphone recognition
- `content.js` — legacy PocketWebTools integration retained in the repository but no longer loaded by the manifest
